# School Camera Monitor

A robust web application designed for regional educational management to securely monitor and streamline school video streams in real-time.

## Features
- **Multi-School Grid View:** Simultaneously monitor video streams from various school locations (entrances, corridors, yards).
- **HLS Stream Support:** Native integration with standard video streaming servers using `.m3u8` protocols.
- **Responsive Dashboard:** Optimized interface for both desktop and mobile monitoring displays.

## Tech Stack
- **Frontend:** HTML5, CSS3 (Flexbox/Grid), JavaScript
- **Video Player:** Video.js
